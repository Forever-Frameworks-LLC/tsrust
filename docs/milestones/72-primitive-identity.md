# Milestone 72: primitive identity and boolean text

Status: complete. Six primitive methods pass compiler, editor, source, native and runtime/resource acceptance: 645 compiler groups, 660 workspace groups, eight matched comparisons and twenty-four fully disposed profiles.

## Scope

Implement zero-argument `valueOf()` on string, boolean, number and the native int extension; implement zero-argument `toString()` on string and boolean. Numeric formatting and radix conversion remain separate work. Receiver evaluation occurs once in source order. Preserve its primitive type for valueOf, including every native i64 value and the complete f64 representation. String.toString and String.valueOf return unchanged text. Boolean.toString returns `true` or `false`.

Use ordinary Rust primitive copies and standard Cow cloning. Static string results stay borrowed. Owned string results copy independently; empty owned strings retain standard Cow clone behavior. Do not consume a reusable receiver, introduce primitive wrapper objects, allocate method tables or change the existing UTF-8 representation. Boxed constructors, reflection and generic Object.prototype methods remain separate inventory entries.

The primitive contracts follow [String.toString/valueOf](https://tc39.es/ecma262/multipage/text-processing.html#sec-string.prototype.tostring), [Boolean.toString/valueOf](https://tc39.es/ecma262/multipage/fundamental-objects.html#sec-boolean.prototype.tostring), and [Number.valueOf](https://tc39.es/ecma262/multipage/numbers-and-dates.html#sec-number.prototype.valueof). The int extension preserves its native i64 type. Coverage adds explicit Boolean.toString and int.valueOf entries, bringing the inventory to 1,926 operations in 28 families.
