# Alert composition and shared parent positioning

The scoped Alert and parent-positioning section passes focused acceptance. Alert
remains partial against the complete pinned Nova contract.

## Delivered behavior

The offline catalog installs editable `Alert`, `AlertTitle`, `AlertDescription` and
`AlertAction` source. Default and destructive variants use semantic theme tokens;
the checked `data-variant` attribute exposes the selected construction-time variant.
An alert defaults to an assertive live role. Callers can choose a polite status role.
Application code owns retry, validation and dismissal behavior.

Shared relative/absolute utilities support bounded independent edge offsets,
percentages, negative offsets and auto resets. Each layout box establishes its
children's containing block. Inline phrasing rejects box positioning. Caller classes
override each edge independently, so long actions can return to normal flow.

The pinned Nova source remains the baseline. This is a partial Alert implementation:
SVG/icon composition, automatic text balancing, generic reactive custom props and
Base UI render composition remain required work. Fixed/sticky positioning, z-index,
transforms and arbitrary CSS are not accepted by this bounded positioning contract.
