# Milestone 54: declared functions as reusable callable values

[Roadmap](../roadmap.md) · [Callable result contracts](./10-callable-results.md)

Status: complete. One 571-group regression, native correctness, twelve matched comparisons and 36 disposal profiles pass.

## Scope

Support passing a declared function to an existing callback consumer, binding it to a local callable, returning it under a compatible existing callable signature, and capturing a bound callable. Current direct function calls remain unchanged. Local names retain precedence over global names.

Reuse the existing callable environment and adapter machinery with a lazily created zero-capture forwarding descriptor for each referenced declared target. Forward to the ordinary Rust function ABI with its exact inferred read, mutate and consume argument modes. The environment itself is reusable and read-only even when a call consumes a data argument. No new runtime storage, dynamic dispatch, implicit copying or cloning is required.

Preserve declaration moves, same-origin replacement, callback access contracts, escaping captures, enclosing loans, operand evaluation order and concrete callable origins. Repeated global references construct fresh empty environments; aliases of one local binding retain its current ownership and loan rules. Support current data parameters and resolved current results, including void and callable-factory results. Ordinary data recursion and definitive callable-result discovery reuse existing analyses. Keep function identifiers distinct from closure identifiers during pruning and remapping.

Array callback hints must recognize declared functions before contextual receiver typing without prechecking inline captures outside receiver loans. Fixed-array specialization retains current conservative callback and whole-source argument rules.

## Acceptance

Binding, reuse, moves, replacement, returns, resolved callable factories, bound/global captures, recursive data targets, concrete origin retention, operand effects and owned-result disposal receive separate cases. Native cases run at optimization levels 0 and 3. Preserve depth and missing/mixed-origin diagnostics; run one settled full regression after focused checks pass.

Matched TypeScript comparisons exercise actual declared callback syntax and bound/returned callable use. Independent traversal and effect expectations validate actual scalar or complete owned results. Benchmark observers remain external to timed kernels and require verified emitted types. Retain earlier measurements and retime only new or affected operations.
