# Milestone 92: Array.flat and Array.flatMap

Status: focused implementation, executable IntelliSense documentation and comparison sources accepted. Combined regression and measurements are accepted at checkpoint 96.

`flat(depth?: int)` copies into an independently mutable array, removing nested levels in encounter order. Depth defaults to 1; nonpositive depth copies without flattening, and positive depth saturates at the leaf rank. Nested receivers require a signed integer literal so the result rank is fixed; rank-one receivers accept dynamic int depths. `flatMap(callback)` invokes a reusable callback in forward order with zero to three Read/Copy value, original-index and source parameters. A concrete scalar or record result contributes one element; an array result contributes its elements, flattening exactly once. Empty input invokes no callbacks, but receiver and argument expressions still evaluate once in order.

Existing dense homogeneous families include null and undefined leaves. Mixed families, nullable union elements, coercion and consuming/mutating callbacks remain unsupported. Named sources stay borrowed and reusable; flat copies retained owned descendants, while flatMap transfers callback-produced owners. Returning a borrowed owned callback parameter requires explicit clone or a fresh value. Checked call metadata supplies concrete editor result types and preserves conflicting specializations conservatively.
