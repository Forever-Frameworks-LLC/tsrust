# Standard library

Reference pages use the same behavioral documentation as editor hover and parameter help. Each method describes its arguments, result, errors and ownership.

Choose a module in the sidebar. Start with [strings](/standard-library/strings), [arrays](/standard-library/arrays), [numbers](/standard-library/numbers) or [collections](/standard-library/collections).

Exact boundary types have separate references: [decimals](/standard-library/decimal), [dates](/standard-library/date), [bytes](/standard-library/bytes), [UUIDs](/standard-library/uuid), [JSON](/standard-library/json) and [schemas](/standard-library/schema). Services use [HTTP](/framework/routing), [SQL](/framework/sql) and [caches](/framework/cache).
