# Blocks

Application layouts assembled from editable components. The pinned inventory includes dashboard, sidebar, login, signup and preview layouts.

Each completed block will provide a live example, narrow and wide layouts, dependencies and exact source. Authentication forms will call application-owned handlers. The framework does not supply authentication policy.

[Dashboard](/ui/blocks/dashboard-01), [sidebar](/ui/blocks/sidebar-01), [login](/ui/blocks/login-01) and [signup](/ui/blocks/signup-01) are the first destinations. Their implementations remain incomplete.
