# Charts

Data visualization is required library work. Shared web/native chart geometry, interaction and accessibility are not implemented yet.

The gallery will separate [chart families](/ui/charts/families) from [data and accessibility](/ui/charts/data-and-accessibility). No chart on these pages is presented as a working component until both targets have an accepted implementation.
