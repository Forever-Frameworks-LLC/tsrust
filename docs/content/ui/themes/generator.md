# Theme generator

The theme generator will edit the same checked tokens stored in `tsrust.config.json`, preview actual components in both modes and export project configuration. It is not implemented yet.

Required controls include semantic colors, aliases, typography, spacing and radii. Validation must preserve the last valid palette, identify alias cycles and show contrast for text, links, fields and focus rings. Runtime token-record updates must retain controls and state.

Until then, edit [project tokens](/ui/foundations/theming) and use the live light/dark toggle to review both palettes.
