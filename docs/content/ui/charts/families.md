# Chart families

The planned gallery covers area, bar, line, pie/donut, radar, radial, scatter and composed charts. Each family needs a live preview, exact source, themes and a data table.

Variants include grouped and stacked series, positive/negative values, missing points, time-series domains and interactive legends. Plot geometry must be shared with native rather than delegated to a browser-only library. These chart components are not implemented yet.
