# Date

Calendar dates, wall-clock times, instants, durations and time zones are separate types. Choose calendar operations for dates and duration arithmetic for elapsed time. A local date and time needs a zone before it identifies an instant.

## Calendar and clock components

`getDay(date)` returns Sunday 0 through Saturday 6. `startOfYear(date)` and `endOfYear(date)` return independent January 1 and December 31 dates, preserving the valid 0001–9999 range. `getHours(time)`, `getMinutes(time)`, `getSeconds(time)` and `getNanoseconds(time)` return 0–23, 0–59, 0–59 and 0–999999999 respectively. Inputs are borrowed and unchanged. No time zone conversion, leap second or mutable JavaScript Date coercion is involved.
