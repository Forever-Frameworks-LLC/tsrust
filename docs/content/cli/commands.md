# Project commands

```text
tsrust new my-app
tsrust check src
tsrust format --check
tsrust build
tsrust run
tsrust dev
tsrust test
tsrust ui list
tsrust ui add button card --offline
```

Run `tsrust --help` for the current command and flag reference. Running `tsrust` in a terminal opens categorized interactive selections; scripts should pass explicit commands.

A complete flag-by-flag reference and shell examples remain required documentation.
