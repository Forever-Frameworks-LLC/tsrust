# Functions and interfaces

Functions use declared parameter and return types. Interfaces describe record shapes; generic interface inheritance and imported bases use checked fields. Callback captures obey ownership rules rather than implicitly copying resources.

The full tutorial will cover generic constraints, inherited fields, closures, function values and diagnostics. Do not assume arbitrary TypeScript metaprogramming is supported.

See [state and ownership](/ui/foundations/state) for component-local callbacks.
