# Performance

Performance comparisons will publish curated snapshots exported from the canonical SQLite evidence store. Documentation builds do not execute benchmarks.

Compare matching operations, input sizes, protocols and source versions. Startup diagnostics are not throughput benchmarks, and a source implementation is not a measured result.

The [strings reference](/standard-library/strings) is the first method-level integration. Overall charts and additional method comparisons remain incomplete.
