# Tsrust vision

A TypeScript-familiar native application language with Rust-backed compilation, strong static typing, inferred borrowing, explicit ownership costs, and no tracing garbage collector.

The implementation prioritizes TypeScript-style syntax with native Rust data structures, methods, and costs. Exact JavaScript semantics are optional; deliberate quirks are documented instead of requiring a compatibility runtime.
