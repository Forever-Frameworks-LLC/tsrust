# Security

Tsrust is experimental. No version currently has a long-term security support
commitment. Use the latest release when reporting a problem, and do not treat
experimental compiler or UI behavior as a security boundary.

Report vulnerabilities through the repository's **Security → Report a
vulnerability** form when private reporting is enabled. Do not include exploit
details, credentials or private source code in a public issue. If the form is
unavailable, open an issue requesting a private reporting channel without
disclosing the vulnerability.

Include the affected version, platform, smallest reproduction, impact and any
known workaround. Native Rust imports and build commands execute native code;
only build projects you trust.
