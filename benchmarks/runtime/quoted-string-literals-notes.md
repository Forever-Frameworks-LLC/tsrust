Quoted String literals use either quote style with byte, Unicode, code-point, identity and control escapes. A paired UTF16 escape represents one Unicode scalar; native Strings reject lone surrogates. Backslash followed by LF, CR, CRLF, U+2028 or U+2029 continues a literal without adding content. The two comparisons retain complete String arrays on the valid UTF8 domain. Their rates cover timed pool setup, dynamic selection, explicit clone and retention. TypeScript clone is identity; native Cow clone shares static literal storage and independently copies owned input. Literal decoding occurs during compilation, so rates do not measure decoding throughput. Static Cow sharing and independent owned copies follow ordinary native ownership; no allocation parity with JavaScript is asserted.
