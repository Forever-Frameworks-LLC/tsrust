# Spread execution compilation

Run `python3 benchmarks/compiler/function-dependencies/run.py --spread-execution arguments --verify-execution --only 32 --output /private/tmp/spread-arguments.json` for untimed validation. Repeat with `annotated` and `fresh`. Add `--measure` only at the architecture milestone. Larger registered groups remain unaccepted and unmeasured while public parser admission and scaling work continue.

Native and TypeScript sources preserve the same scalar result through nested calls. Argument and fresh-callee variants construct each one-element source array before its outer call. The annotated variant traverses written generic contracts. The independent native and Node-after-tsc execution oracle is `7\n`. Exact source hashes, checks and tool identities are retained; timing still uses two warmups and eleven samples.
